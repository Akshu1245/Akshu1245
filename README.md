# Akshay Kammar

Student founder in Bengaluru building **RaksHex** ([rakshex.in](https://rakshex.in)).

RaksHex is an **AI Action Control Plane**: runtime authority for AI spend, access, safety, and policy across providers. It authorizes consequential agent actions (ALLOW or DENY) with delegated authority, policy checks, credential mediation, and an Action Ledger.

**Not another AI gateway.** Gateways route. RaksHex decides whether an action is allowed to execute.

Status: **private beta**, learning by shipping. No fake customer logos.
